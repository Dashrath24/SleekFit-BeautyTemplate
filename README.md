# 💎 Sleek Fit & Beauty  
A beautifully crafted, fully responsive **beauty and fitness** website built from a PSD file using **HTML**, **CSS**, and **JavaScript** — completed independently within **24 hours**. This project demonstrates my design-to-code conversion skills, attention to visual detail, and ability to work under tight deadlines.
